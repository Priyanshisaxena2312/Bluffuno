# BluffUno 🃏

BluffUno is an interactive online card game where players use strategy, deception, and smart decisions to outplay their opponents.

## 🚀 Live Demo

[**Play BluffUno →**](https://bluffuno.vercel.app/)

## ✨ Features

- Interactive card game interface.
- Engaging bluff-based gameplay.
- Strategic decision-making.
- User-friendly design.
- Responsive UI.
- Smooth gameplay experience.

## 🛠️ Tech Stack

- Add your frontend framework here.
- JavaScript
- HTML5
- CSS3

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd bluffuno
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
